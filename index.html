仕様・注意事項（必ず確認）
【15秒周期】ページ表示中、端末時刻に合わせて15秒ごとに判定レコードを生成します。Safariがバックグラウンドに移るとタイマーは停止・遅延する場合があります。停止中に遡って予測を生成しません。
【無料データ】Frankfurterはリアルタイム市場価格ではなく日次等の基準レート。Twelve DataのForex API v2は分単位データのため、15秒先の方向判定に利用しません。
【HIGH/LOW条件】本ツールがHIGH/LOWを出すのは、検証用の手動入力モードで異なる時刻の新鮮なサンプルが十分蓄積され、方向と変動幅の条件がそろった場合のみです。これは学習済みAIの予測ではありません。手動入力の時間差・価格精度に注意。
【事後照合】対象時刻から前後4秒以内に観測された新しい価格がある場合だけ勝敗判定します。同値は判定不能とします。後から記録されたデータで過去の予測を書き換えません。
【API上限】Twelve Data Basicは8クレジット/分・800クレジット/日。ここでは最大1回/分のポーリングを行い、必要以上の呼び出しを防ぎます。手動更新にも60秒間隔制限を適用しています。通信失敗時は古い価格で予測しません。
【セキュリティ】APIキーはsessionStorageにのみ保存（タブが閉じられたら通常消去される）。公衆端末では使用しないでください。GitHub Pagesは静的配信のみで、秘密鍵の安全なサーバー保管には対応しません。
【用途】研究・記録専用。短期バイナリー取引は損失リスクが高く、価格提供元とASTRO側の配信価格・約定時刻が異なる場合があります。
